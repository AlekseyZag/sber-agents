### 1. Название проекта

Название должно отражать суть проекта и легко запоминаться. Предлагаю назвать ваш проект:

#### **BankingAssistant**

---

### 2. Описание проекта

Ваш проект представляет собой специализированного ИИ-ассистента, предназначенного для поддержки банковских клиентов. Основная цель ассистента — обеспечить удобное взаимодействие пользователей с банком посредством удобного интерфейса и быстрого реагирования на запросы клиентов.

Ассистент сможет отвечать на часто задаваемые вопросы, помогать клиентам совершать операции онлайн, поддерживать диалог в естественной форме, обрабатывать голосовые команды и визуализировать финансовую информацию графически. Банк получит возможность снизить нагрузку на службу поддержки и повысить удовлетворенность клиентов благодаря персонализированному обслуживанию.

---

### 3. Целевая аудитория

Цель проекта — удовлетворить потребности двух основных групп:

- **Клиенты банка**: Пользователи смогут быстро получать помощь и консультацию по вопросам счетов, карт, кредитов и инвестиций.
- **Сотрудники банка**: Повышение эффективности сотрудников службы поддержки и снижение нагрузки на горячую линию путем автоматизации рутинных операций.

---

### 4. Основные функции и возможности

Вот основные функции и возможности вашего ассистента:

- Автоматическое распознавание вопросов клиента и предоставление точного ответа.
- Возможность обработки простых транзакций (например, проверка баланса счета).
- Поддержка взаимодействия с клиентами через чат и голосовой интерфейс.
- Интеграция с внутренней системой банка для доступа к персональным данным клиентов (безопасно и конфиденциально).
- Предоставление рекомендаций по продуктам банка на основании истории запросов и предпочтений клиента.
- Отображение финансовых отчетов и статистики в удобной визуальной форме.

---

### 5. Технологии и подходы из курса

Давайте определимся, как именно использовать изученные вами концепции и технологии:

- **Работа с LLM через API**: Мы будем интегрироваться с современными моделями больших языковых моделей (LLMs) через OpenAI-совместимый API, чтобы обеспечить высокую точность ответов на вопросы клиентов.
- **Structured Output**: Используем техники структурированного вывода для формирования правильных форматов ответа (например, таблицы или списки действий).
- **Мультимодальность**: Ассистент будет поддерживать работу с голосом и изображениями. Например, клиент сможет отправить скриншот выписки по счету, а ассистент обработает изображение и даст пояснения.
- **RAG (Retrieval-Augmented Generation)**: Включаем интеграцию с корпоративной базой знаний банка, чтобы обеспечивать точные и релевантные ответы на специфичные банковские вопросы.
- **Агентные паттерны и сложные workflow с LangGraph**: Создаем сложную систему принятия решений, способную выбирать наилучший путь выполнения задач, включая обработку запросов с несколькими этапами.
- **MCP (Model Context Protocol)**: Реализуем интеграцию с внешними инструментами и сервисами банка для расширения функциональности ассистента.

---

### 6. План развития проекта по модулям курса

Теперь давайте посмотрим, как проект будет эволюционировать от модуля к модулю:

- **Модуль 1**: Базовая версия ассистента на основе готовых шаблонов. Подключение простой интеграции с OpenAI API для базовых функций.
- **Модуль 2**: Усовершенствование модели ответов с использованием техник структурированного вывода (формирование таблиц, списков).
- **Модуль 3**: Реализация мультисессионности и состояния разговора (context-awareness). Появляется способность помнить предыдущие запросы и вести продолжительный диалог.
- **Модуль 4**: Начало интеграции мультимодальности — поддержка голосового ввода и обработка изображений (например, чеков и квитанций).
- **Модуль 5**: Первая реализация подхода RAG для повышения точности ответов на специализированные вопросы.
- **Модуль 6**: Полноценная интеграция с корпоративной базой знаний банка для предоставления наиболее актуальной информации.
- **Модуль 7**: Мониторинг производительности и качества работы ассистента. Анализ ошибок и оптимизация поведения системы.
- **Модуль 8**: Использование агентных паттернов для реализации сложной логики принятия решений и автоматизации процессов.
- **Модуль 9**: Расширение функционала с помощью технологий LangGraph для усложненных цепочек действий.
- **Модуль 10**: Дальнейшее развитие интеграционных возможностей с помощью протокола Model Context Protocol (MCP).
- **Модуль 11**: Оценка безопасности и качества разработанной системы. Тестирование и улучшение устойчивости ассистента.
- **Модуль 12**: Финальная демонстрация и презентация готового продукта перед преподавателем и сокурсниками.
