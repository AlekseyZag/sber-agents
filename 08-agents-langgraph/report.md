# Отчет: Инструмент конвертации валют для ReAct агента

## 🔧 Какой инструмент реализован?

**`currency_converter`** - конвертация валют по актуальным курсам
- Использует ExchangeRate-API.com
- Декоратор `@tool` из LangChain
- Поддерживает все основные валюты (USD, EUR, RUB, CNY и др.)

## 🧠 Как агент принимает решения?

**ReAct паттерн (Reason + Act):**

1. **Think** - анализирует вопрос пользователя
2. **Decide** - выбирает действие:
   - Простые вопросы ("привет") → прямой ответ
   - Банковские вопросы → `rag_search`
   - Валютные вопросы → `currency_converter`
3. **Respond** - формирует ответ

## 🔄 Чем агент отличается от RAG-цепочки?

| Характеристика | RAG-цепочка | ReAct агент |
|---|---|---|
| **Логика** | Всегда ищет в документах | Сам выбирает нужный инструмент |
| **Источники** | Только документы | Документы + API + знания модели |
| **Адаптивность** | Жесткая схема | Гибкое поведение |
| **Простые вопросы** | Излишне сложно | Быстрый ответ |

**Результат:** Агент стал умнее, быстрее и функциональнее 🎯
