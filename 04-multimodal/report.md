# Отчёт по проекту «Персональный финансовый советник»

## Описание проекта

Telegram-бот для учёта личных финансов, который извлекает транзакции из текстов и изображений, автоматически классифицирует их и формирует сводки.

## Реализованные возможности

- [x] Извлечение транзакций из текстовых сообщений
- [x] Обработка изображений чеков и скриншотов
- [x] Автоматическая категоризация доходов и расходов
- [x] Формирование отчётов о балансе и статистике
- [x] Ведение истории транзакций в рамках сессии
- [x] Интеграция с локальными моделями через Ollama

- Python 3.11
- uv (менеджер зависимостей)

- Используемые модели: `qwen2.5:7b-instruct`, `llama3.2:1b`, варианты vision-моделей через Ollama

## Облачный сервер

- Провайдер: immers.cloud
- Конфигурация: GPU NVIDIA Tesla V100 32 GB (пока без установленного драйвера)
- Развёрнутый Ollama-сервер с моделями `qwen2.5:7b-instruct` и `llama3.2:1b`

## Основные вызовы и решения

- **Отсутствие NVIDIA-драйвера на ВМ:** Ollama запускался в CPU-режиме; выполнена диагностика (`nvidia-smi`, `lspci`), рекомендована установка драйвера.
- **Перенастройка бота с OpenRouter на Ollama:** обновлены переменные окружения (`OPENAI_BASE_URL`, `MODEL_TEXT`, `MODEL_IMAGE`), чтобы направить запросы на локальный сервер.
- **Корректное переопределение systemd unit для Ollama:** создан override-файл с переменными окружения `OLLAMA_HOST` и `OLLAMA_ORIGINS`, сервис перезапущен.
- **Тестирование OpenAI-совместимого API:** проведены запросы к `/v1/models` и `/v1/chat/completions`, подтверждена работоспособность и устранены ошибки 404.

## Что узнал нового

1. Практика настройки Ollama как сетевого сервиса через systemd overrides.
2. Особенности работы OpenAI Python SDK с кастомным `base_url` и structured output.
3. Настройка PowerShell-команд с `--%` для корректной передачи JSON в `curl`.
4. Последовательность действий для диагностики доступности GPU на удалённой ВМ.
5. Подбор и сравнение vision-моделей в Ollama для финансового анализа изображений.
