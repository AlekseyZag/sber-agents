# MCP Bank Agent Server

MCP сервер для банковского агента с инструментами поиска продуктов и конвертации валют.

## 📋 Описание

Этот MCP сервер предоставляет три инструмента для расширения возможностей банковского агента:

1. **search_products** - поиск актуальных продуктов банка (вклады, кредиты, карты, счета)
2. **currency_converter** - конвертация валют по актуальным курсам ЦБ РФ
3. **calculate_deposit_profit** - расчет доходности вклада с учетом капитализации процентов

## 🛠 Инструменты

### 1. search_products

Универсальный поиск актуальных банковских продуктов с гибкой фильтрацией.

**Параметры:**
- `product_type` - тип продукта: `deposit`, `credit`, `debit_card`, `credit_card`, `account`
- `keyword` - ключевое слово для поиска в названии и описании
- `min_amount` - минимальная сумма (ищет продукты доступные от этой суммы)
- `max_amount` - максимальная сумма (ищет продукты доступные до этой суммы)
- `min_rate` - минимальная процентная ставка
- `max_rate` - максимальная процентная ставка
- `currency` - валюта продукта: `RUB`, `USD`, `EUR`

**Примеры использования:**

```python
# Найти все вклады
search_products(product_type="deposit")

# Найти вклады с ставкой от 15%
search_products(product_type="deposit", min_rate=15.0)

# Найти кредиты до 1 млн рублей
search_products(product_type="credit", max_amount=1000000)

# Найти продукты с кешбэком
search_products(keyword="кешбэк")

# Найти кредитные карты с беспроцентным периодом
search_products(product_type="credit_card", keyword="без %")
```

**Что возвращает:**
Форматированный список найденных продуктов (топ-10) с полной информацией:
- Название и описание
- Процентная ставка (для вкладов и кредитов)
- Диапазон сумм
- Срок
- Особенности продукта

### 2. currency_converter

Конвертация валют по актуальным курсам ЦБ РФ с поддержкой всех основных валют.

**Параметры:**
- `from_currency` - исходная валюта: `RUB`, `USD`, `EUR`, `CNY`, `GBP`, `CHF`, `JPY`, `TRY`
- `to_currency` - целевая валюта: `RUB`, `USD`, `EUR`, `CNY`, `GBP`, `CHF`, `JPY`, `TRY`
- `amount` - сумма для конвертации (опционально, если не указана - вернется только курс)

**Примеры использования:**

```python
# Узнать курс доллара к рублю
currency_converter(from_currency="USD", to_currency="RUB")

# Конвертировать 100 долларов в рубли
currency_converter(from_currency="USD", to_currency="RUB", amount=100)

# Конвертировать 1000 рублей в евро
currency_converter(from_currency="RUB", to_currency="EUR", amount=1000)

# Конвертировать доллары в евро (через рубли)
currency_converter(from_currency="USD", to_currency="EUR", amount=100)
```

**Что возвращает:**
- Результат конвертации с указанием суммы (если amount указан)
- Текущий курс валют
- Обратный курс для справки

**Источник данных:** API ЦБ РФ (https://www.cbr-xml-daily.ru/latest.js)

### 3. calculate_deposit_profit

Расчет доходности вклада с учетом капитализации процентов.

**Параметры:**
- `initial_amount` - начальная сумма вклада в рублях (минимум 1000)
- `annual_rate` - годовая процентная ставка в процентах (0-100)
- `term_months` - срок вклада в месяцах (1-60)
- `capitalization` - капитализация процентов (начисление процентов на проценты), по умолчанию `False`

**Примеры использования:**

```python
# Расчет простого вклада без капитализации
calculate_deposit_profit(
    initial_amount=100000,
    annual_rate=15.0,
    term_months=12,
    capitalization=False
)

# Расчет вклада с капитализацией
calculate_deposit_profit(
    initial_amount=500000,
    annual_rate=18.0,
    term_months=24,
    capitalization=True
)

# Расчет краткосрочного вклада
calculate_deposit_profit(
    initial_amount=1000000,
    annual_rate=16.0,
    term_months=6,
    capitalization=True
)
```

**Что возвращает:**
- Итоговую сумму на конец срока
- Полученный доход (прибыль)
- Эффективную годовую ставку
- Сравнение эффективной и номинальной ставки (при капитализации)

**Формулы расчета:**
- **Без капитализации:** простая формула процентов
  - Итоговая сумма = начальная × (1 + ставка/100 × срок_в_годах)
- **С капитализацией:** формула сложных процентов с ежемесячной капитализацией
  - Итоговая сумма = начальная × (1 + ставка/100/12)^(срок_в_месяцах)
- **Эффективная ставка:** показывает реальную доходность с учетом капитализации
  - Эффективная ставка = ((итоговая/начальная)^(1/срок_в_годах) - 1) × 100

## 📊 База данных продуктов

База продуктов находится в файле `data/bank_products.json`.

**Структура продукта:**

```json
{
  "id": "deposit_01",
  "product_type": "deposit",
  "name": "Вклад Пополняй",
  "description": "Вклад с возможностью пополнения и частичного снятия",
  "rate_min": 15.0,
  "rate_max": 16.0,
  "amount_min": 1000,
  "amount_max": 10000000,
  "currency": "RUB",
  "term_months": "3-36",
  "features": ["пополнение", "частичное снятие", "онлайн открытие"]
}
```

**Типы продуктов:**
- `deposit` - вклады
- `credit` - кредиты
- `debit_card` - дебетовые карты
- `credit_card` - кредитные карты
- `account` - счета

**Текущие продукты (14 штук):**
- 4 вклада (Пополняй, Сохраняй, Накопительный счёт, Пенсионный)
- 3 кредита (наличными, рефинансирование, под залог)
- 3 дебетовые карты (СберКарта, Золотая, Молодёжная)
- 2 кредитные карты (СберКарта, Золотая)
- 2 счета (Мультивалютный, Зарплатный)

## 🔧 Технические детали

**Транспорт:** streamable-http (HTTP MCP server)  
**Порт:** 8000 (по умолчанию для FastMCP)  
**URL:** http://localhost:8000/mcp

**Зависимости:**
- `mcp>=1.11.0` - FastMCP framework
- `requests>=2.31.0` - HTTP клиент для API ЦБ РФ

**Логирование:** INFO level, все важные операции логируются

## 🎯 Разделение ответственности инструментов

### rag_search (из основного агента)
- Статические документы банка (PDF)
- Общие правила и условия
- Инструкции и политики
- Исторические данные

### search_products (этот MCP сервер)
- Актуальные продукты банка
- Текущие ставки и условия
- Доступные предложения
- Динамические данные

### currency_converter (этот MCP сервер)
- Курсы валют в реальном времени
- Конвертация между валютами
- Актуальные данные ЦБ РФ

### calculate_deposit_profit (этот MCP сервер)
- Расчет доходности вклада
- Учет капитализации процентов
- Расчет эффективной ставки
- Финансовые расчеты

## 🔄 Обновление данных

**Продукты банка:**
Обновляются вручную через редактирование `data/bank_products.json`.

**Курсы валют:**
Обновляются автоматически при каждом вызове `currency_converter` через API ЦБ РФ.
