Workflow по разработке бота
===========================

1. Работай только по шагам из docs/tasklist.md, не перескакивай.
2. Перед каждой итерацией — предложи решение и короткие фрагменты кода для согласования.
3. После одобрения — реализуй задачу итерации.
4. Дожидайся подтверждения результата.
5. После подтверждения:
  - Обнови прогресс и статусы в docs/tasklist.md
  - Отметь чекбоксы у выполненных задач
  - Получи согласие двигаться дальше
6. Сделай коммит изменений в репозиторий.

Всегда следуй принципам из docs/vision.md и docs/conventions.md. Минимум действий, максимум прозрачности.
