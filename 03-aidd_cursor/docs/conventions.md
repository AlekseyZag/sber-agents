Правила разработки кода для code-ассистента
===========================================

1. Пиши только рабочий, минимально необходимый код. Избегай сложных абстракций и шаблонов.
2. Не используй то, что не требуется задачей здесь и сейчас (YAGNI).
3. Четко следуй принципу KISS — максимальная простота во всем.
4. Предпочитай явность и читаемость кода. Не сокращай названия ради экономии символов.
5. Логика и обработка ошибок — только самая необходимая, без усложнений.
6. Используй только утвержденные технологии и инструменты из vision.md.
7. Всегда поддерживай совместимость с минимальным окружением проекта.
8. Не внедряй никаких сторонних зависимостей без отдельного согласования.
9. Конфигурация и логгирование — по явным утвержденным паттернам.
10. Код должен быть готов к быстрой проверке и запуску без дополнительной доработки.
