# Рекомендации по моделям Ollama для 16GB RAM

## 🎯 Рекомендуемые модели для 16GB RAM

### ⚡ Легкие модели (2-4 GB) - Быстрые, для простых задач

1. **llama3.2:3b** ⭐ Рекомендуется для начала
   - Размер: ~2 GB
   - Скорость: Очень быстрая
   - Качество: Хорошее для простых задач
   - Использование: `OLLAMA_MODEL=llama3.2:3b`

2. **llama3.2:1b**
   - Размер: ~1 GB
   - Скорость: Максимальная
   - Качество: Базовое
   - Использование: `OLLAMA_MODEL=llama3.2:1b`

### 🎯 Оптимальные модели (4-6 GB) - Баланс качества и скорости

3. **llama3.1:8b** ⭐ Лучший баланс
   - Размер: ~4.9 GB
   - Скорость: Быстрая
   - Качество: Отличное
   - Использование: `OLLAMA_MODEL=llama3.1:8b`

4. **mistral:7b**
   - Размер: ~4.1 GB
   - Скорость: Быстрая
   - Качество: Отличное
   - Использование: `OLLAMA_MODEL=mistral:7b`

5. **qwen2.5:7b** ⭐ Хорошо для русского языка
   - Размер: ~4.7 GB
   - Скорость: Быстрая
   - Качество: Отличное, хорошо понимает русский
   - Использование: `OLLAMA_MODEL=qwen2.5:7b`

**Примечание:** Ollama автоматически выбирает оптимальный формат квантования. Не нужно указывать формат (`-q4_K_M`, `-q8_0`) в имени модели.

## 📊 Информация о квантовании

Ollama автоматически выбирает оптимальный формат квантования при установке модели. Обычно это `q4_K_M` для моделей 7B-8B, что обеспечивает хороший баланс между качеством и размером.

**Не нужно указывать формат квантования в имени модели** - просто используйте `llama3.1:8b` вместо `llama3.1:8b-q4_K_M`.

## 🎯 Рекомендации для вашего проекта

### Для RAG-системы (поиск и ответы на вопросы):

**Рекомендуется:**
- **llama3.1:8b** - лучший баланс качества и скорости (~4.9 GB)
- **qwen2.5:7b** - если нужна лучшая поддержка русского языка (~4.7 GB)

**Альтернатива:**
- **llama3.2:3b** - если нужна максимальная скорость (~2 GB)

### Настройка в .env:

```bash
# LLM Configuration
LLM_PROVIDER=ollama
OLLAMA_BASE_URL=http://localhost:11434
OLLAMA_MODEL=llama3.1:8b
OLLAMA_MODEL_QUERY_TRANSFORM=llama3.1:8b

# Embeddings (оставляем HuggingFace)
EMBEDDING_PROVIDER=huggingface
HUGGINGFACE_EMBEDDING_MODEL=intfloat/multilingual-e5-base
HUGGINGFACE_DEVICE=cpu
```

## 📥 Установка моделей

```bash
# Установить рекомендуемую модель
ollama pull llama3.1:8b

# Или для русского языка
ollama pull qwen2.5:7b

# Проверить установленные модели
ollama list
```

## ⚠️ Важные замечания

1. **Первый запуск**: Модель загрузится при первом использовании (может занять время)
2. **Память**: Следите за использованием RAM, особенно при больших моделях
3. **Температура**: В коде используется temperature=0.9 для основного LLM и 0.4 для query transform
4. **Производительность**: На CPU модели работают медленнее, чем на GPU

## 🔍 Проверка работы

После настройки проверьте:
1. Запустите бота
2. Проверьте логи - должна быть строка: `Main LLM initialized: ollama/llama3.1:8b`
3. Задайте вопрос в боте
4. Проверьте `/index_status` - должна отображаться информация о LLM
