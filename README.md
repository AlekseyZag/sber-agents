# 🚀 **SberAgents** - Учебный проект по разработке банковского ИИ-ассистента

## О проекте

Этот репозиторий предназначен для выполнения учебных заданий по курсу "AI-driven разработка ИИ-агентов". Цель проекта — освоить разработку и внедрение интеллектуальных агентов для решения бизнес-задач банка.

## Как запускать

Для запуска учебного окружения потребуется установить зависимости из файла `requirements.txt`. По мере прохождения курса инструкции по запуску конкретных модулей будут обновляться здесь.

### Установка зависимостей

```bash
pip install -r requirements.txt
```

### Запуск Jupyter Notebook

```bash
jupyter notebook
```

Откройте файл `.ipynb` соответствующего задания и следуйте инструкциям.
